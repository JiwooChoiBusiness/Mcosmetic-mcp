## 잘 묻는 요령

- **고객명·품목명·날짜를 넣으면 정확해집니다.** 예: "10월 22일 오전 9시쯤 누리뷰티가 보낸 메일"
- **ID를 알면 ID로 물으세요.** E-1001, RFQ-2026-00120, SO-20261018-00109, MC-CIC-SR050, CUST-00024, ERR-0008
- **개수·목록 질문**(몇 건, 모두, 담당자별)은 AI가 `find_emails`/`find_cases`로 전체를 세므로 정확합니다.
- **근거를 같이 달라고** 하면 행 번호와 원문을 인용합니다. 예: "근거 원문과 행 번호도 같이 보여줘"
- 대시보드 KPI(10월 22일 하루)와 누적 건수는 기준이 다르므로 섞지 않도록 되어 있습니다.

# ERP 실행 (데모) — 말로 시켜 보기

ERP·메일 실행 도구는 **데모 시뮬레이션**입니다. 실제로 등록·발송되지 않고 저장되지도 않지만, 응답 형식과 금액 계산은 데이터의 ERP 기록과 같습니다.
주문등록·메일 발송은 AI가 먼저 **"반영 예정 데이터"**를 보여주고, "승인"이라고 답해야 실행합니다.
